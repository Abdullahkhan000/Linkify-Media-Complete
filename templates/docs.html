Documentation

Everything you need to integrate Linkify Media into your application.

Authentication

All API requests must include your API Key in the request headers. You can find or create your keys in the Dashboard.

Request Header

X-API-Key: your_uuid_api_key_here

Base URL

All API endpoints are relative to the following base URL:

https://linkify-media.com/api/

Endpoints

GET

/search/

Fetch verified media links for a specific movie or TV show title.

Query Parameters

Parameter Type Required Description
q string Yes The title of the movie or TV show.
type string No Either movie (default) or tv.
POST

/batch/

Pro Only

Fetch links for multiple items in a single request (Max 10 items).

Request Body (JSON)

{
  "items": [
    { "q": "Inception", "type": "movie" },
    { "q": "The Last of Us", "type": "tv" }
  ]
}
GET

/usage/

Check your current plan limits and remaining daily request quota.

Code Examples

cURL

curl -X GET "https://linkify-media.com/api/search/?q=Inception" \
     -H "X-API-Key: your_api_key_here"

Python (Requests)

import requests

url = "https://linkify-media.com/api/search/"
headers = {
    "X-API-Key": "your_api_key_here"
}
params = {
    "q": "Inception",
    "type": "movie"
}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
