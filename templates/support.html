Frequently Asked Questions

6 articles
How do I pass the API key in my requests?
Pass your generated API key in the request header as X-API-Key: YOUR_KEY. Avoid placing keys in public client-side code or URLs.
What media types are supported?
The API supports movie and tv. Aliases such as show, anime, and series are also accepted and mapped to the appropriate media type.
What happens when I exceed my daily rate limit?
The API returns 429 Too Many Requests. Check your usage dashboard, wait for the daily reset, or upgrade your plan for a higher allowance.
Why did my search return no verified media?
Try the official title, remove extra punctuation, or specify the correct type. Very new, obscure, or incorrectly spelled titles may not have enough provider metadata.
How do I request only selected response fields?
Use the comma-separated fields parameter, for example fields=title,poster,imdb. This keeps responses smaller and easier to consume.
How can I report a billing or account issue?
Email support with your account email, approximate event time, and any checkout or webhook message. Never include your API key or payment details in the message.
